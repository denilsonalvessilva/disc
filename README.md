# 🎯 Plano de Gestão Financeira para Salão de Beleza

Bem-vindo(a) ao repositório de organização e gestão financeira do seu salão de beleza! Este material foi estruturado para guiar a transição de um caixa misturado para uma gestão profissional, previsível e lucrativa.

---

## 📌 Objetivos Principais

1. **Separação de Contas**: Separar 100% das finanças pessoais das finanças da empresa.
2. **Pró-labore Fixo**: Definir uma remuneração fixa diária/mensal para evitar retiradas desordenadas.
3. **Ficha Técnica & Margem**: Calcular o custo exato por cliente/procedimento (cílios, unhas, sobrancelhas) e otimizar margens.
4. **Fluxo de Caixa Simples**: Controlar todas as entradas e saídas de forma diária e prática.
5. **Estoque Inteligente**: Gerir insumos sem desperdício, compras impulsivas ou produtos vencidos.
6. **Ponto de Equilíbrio**: Acompanhar e atingir semanalmente o faturamento necessário para cobrir os custos fixos.
